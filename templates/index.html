Fine-tune an existing model

Fine Tune uses the same five-step project workflow as Train. Create a separate project for the new area, prepare its labels and annotations, build its dataset, then select a compatible existing trained model in Step 5. The original checkpoint is retained; fine-tuning produces a separate checkpoint.

Use a distinct project and label key for the new area. Dataset folders in this application are currently label-scoped, not fully project-scoped; do not reuse an existing label name until project-scoped storage is implemented.
